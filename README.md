# 🥞 Блинчики - Сайт про блины

Добро пожаловать на сайт, посвященный вкусным и традиционным блинам русской кухни!

## О проекте

Это красивый и современный веб-сайт, рассказывающий о блинах - одном из самых любимых блюд в русской кулинарной традиции. Сайт содержит:

- **Главная страница** с приветственной информацией
- **Раздел рецептов** с 6 популярными рецептами блинов
- **История блинов** - об их происхождении и значении в русской культуре
- **Форма контакта** для обратной связи

## Особенности дизайна

✨ **Современный и адаптивный дизайн**
- Полностью отзывчивый макет (работает на мобильных, планшетах и десктопах)
- Красивая цветовая схема с теплыми тонами (коричневый, бежевый)
- Плавные переходы и анимации
- Символы блинов (emoji) для дополнительной атмосферности

🎨 **Визуальные элементы**
- Градиентные фоны
- Наведение на карточки рецептов с подъемом
- Анимированные подчеркивания в меню
- Четкая типография

📱 **Мобильная оптимизация**
- Адаптивная сетка рецептов
- Липкое меню навигации
- Оптимизированные размеры шрифтов для мобильных устройств

## Структура проекта

```
.
```

## Как использовать

1. Откройте файл `index.html` в веб-браузере
2. Навигируйте по разделам с помощью меню в верхней части страницы
3. Просмотрите рецепты блинов
4. Узнайте об истории блинов
5. Свяжитесь с нами через форму контакта

## Технологии

- HTML5
- CSS3 (с использованием CSS переменных и Grid/Flexbox)
- Адаптивный дизайн (медиа-запросы)

## Рецепты на сайте

1. 🥞 **Классические блины** - Традиционные тонкие блины
2. 🫐 **Блины с ягодами** - Блины с черникой, малиной или клубникой
3. 🥞 **Блины с творогом** - Пышные блины с творогом
4. 🍯 **Блины с медом** - Блины с медом и орехами
5. 🍄 **Блины с грибами** - Пикантные блины с грибной начинкой
6. 🧀 **Блины с сыром** - Блины с расплавленным сыром
