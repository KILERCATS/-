# 🥞 Блинчики - Сайт про блины

Добро пожаловать на сайт, посвященный вкусным и традиционным блинам русской кухни!

## О проекте

Это красивый и современный веб-сайт, рассказывающий о блинах - одном из самых любимых блюд в русской кулинарной традиции. Сайт содержит:

- **Главная страница** с приветственной информацией и примерами рецептов
- **Раздел рецептов** с 4+ полными рецептами, ингредиентами и инструкциями
- **История блинов** с временной шкалой, фактами и традициями
- **О проекте** с информацией о команде и ценностях
- **Контакты** с формой обратной связи, FAQ и контактной информацией

## Особенности дизайна

✨ **Современный и адаптивный дизайн**
- Полностью отзывчивый макет (работает на мобильных, планшетах и десктопах)
- Красивая цветовая схема с теплыми тонами (коричневый, бежевый)
- Плавные переходы и анимации
- Символы блинов (emoji) для дополнительной атмосферности

🎨 **Визуальные элементы**
- Градиентные фоны
- Наведение на карточки рецептов с подъемом
- Анимированные подчеркивания в меню
- Четкая типография

📱 **Мобильная оптимизация**
- Адаптивная сетка рецептов
- Липкое меню навигации
- Оптимизированные размеры шрифтов для мобильных устройств

## Структура проекта

```
.
├── index.html       # Главная страница
├── recipes.html     # Страница с полными рецептами блинов
├── history.html     # История блинов в России

├── styles.css       # Единые стили для всех страниц
```

## Как использовать

1. Откройте файл `index.html` в веб-браузере
2. Используйте главное меню навигации для перемещения между страницами:
   - **Главная** - Обзор сайта с основной информацией и примерами рецептов
   - **Рецепты** - Полные рецепты 4+ блюд с ингредиентами и пошаговыми инструкциями
   - **История** - Подробная история блинов, временная шкала и интересные факты
   - **О нас** - Информация о команде, ценностях и миссии проекта
   - **Контакты** - Форма обратной связи, FAQ и контактная информация
3. На каждой странице есть единый навигационный стиль для удобства использования
